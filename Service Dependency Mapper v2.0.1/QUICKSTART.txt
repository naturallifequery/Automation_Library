SERVICE DEPENDENCY MAPPER 2.0.1 - QUICK START
============================================================

PURPOSE
-------
Run a read-only service dependency scan directly on this Windows
computer and create one interactive offline HTML report.

REQUIREMENTS
------------
- Windows PowerShell 5.1.
- Windows 10/11 or Windows Server with CIM service information.
- A browser for the HTML report.
- Administrator elevation is recommended for complete details.

No Python, WinRM, agent, installation, JSON, internet connection,
paid licence, web server, or PowerShell module is required.

EASIEST METHOD
--------------
1. Extract the ZIP to a local folder.
2. Right-click Start-ServiceDependencyMapper.cmd.
3. Choose Run as administrator.
4. Confirm the report folder.
5. Leave Include stopped services selected.
6. Click Scan this computer.
7. Wait for the completion message and review the HTML report.

The CMD launcher uses ExecutionPolicy Bypass only for the PowerShell
process it starts. It does not permanently change execution policy.
Group Policy settings still take precedence.

CONSOLE METHOD
--------------
Open an elevated Windows PowerShell window in the project folder:

powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass `
    -File .\ServiceDependencyMapper.ps1 `
    -NoGui `
    -OpenReport

OUTPUT
------
The default output folder is:

Reports\

The report name is similar to:

Service-Dependency-Report-SERVER01-20260829-120000.html

WHAT IT READS
-------------
- Windows service name, display name, state and start mode.
- Service account, process ID and redacted binary path.
- Declared service dependencies and dependent services.
- Current service-owned TCP listeners and outbound connections.

WHAT IT DOES NOT CHANGE
-----------------------
- Services or processes.
- Firewall or network settings.
- Registry or scheduled tasks.
- WinRM or PowerShell remoting.
- Machine or user execution policy.

IMPORTANT
---------
- This is a point-in-time scan and can miss inactive connections.
- Several services can share one process. The report labels shared-PID
  network evidence because attribution may be ambiguous.
- A connection is evidence for review, not permission to block it.
- Store the HTML securely because it contains infrastructure details.

TROUBLESHOOTING
---------------
If the menu does not open, use the CONSOLE METHOD above.

If details are missing, close PowerShell and run it as Administrator.

If TCP sections are empty, confirm Get-NetTCPConnection exists:

Get-Command Get-NetTCPConnection

If organisation Group Policy blocks the script, do not weaken the
policy. Follow the approved signing or allow-listing process.
